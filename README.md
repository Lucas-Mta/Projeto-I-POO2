### 📝 Sobre o Projeto

Este projeto foi desenvolvido como parte das atividades da disciplina de Programação Orientada a Objetos II. Ele implementa uma aplicação Java com interface gráfica para manipulação de arquivos de texto, trazendo recursos visuais avançados e personalizáveis. É uma aplicação prática dos conceitos de OOP, boas práticas de desenvolvimento e arquitetura de software.

---

### ✨ Funcionalidades Detalhadas

-   **Abertura e Exibição de Arquivos de Texto:** O usuário pode abrir arquivos `.txt` e visualizar o conteúdo em uma área de texto central com rolagem e quebra de linha automática. É possível fechar o arquivo, limpando a área de exibição.
-   **Interface Gráfica Intuitiva:** A aplicação utiliza **Java Swing** para construir menus, diálogos de ajuda e sobre, além de uma área central para exibição e animações.
-   **Animações Dinâmicas:** Quando nenhum arquivo está aberto, a área central exibe animações personalizáveis (círculo, estrela, hexágono).
-   **Personalização:** A cor, velocidade e o padrão das animações podem ser alterados pelo usuário através do menu "Configurações".
-   **Diálogos de Ajuda e Sobre:** Inclui um sistema de ajuda detalhado (com imagens) explicando cada funcionalidade e um diálogo "Sobre" com informações do projeto, versão e um link para o GitHub.
-   **Boas Práticas de UI:** A interface foi pensada para a melhor experiência do usuário, com feedback visual, botões estilizados, efeitos de *hover* e uma organização clara dos menus.

---

### 🧠 O que Aprendemos com o Projeto

Este repositório é um excelente exemplo de como integrar diferentes áreas da programação Java para criar uma aplicação completa. Com o código, você pode aprender sobre:

-   **Programação Orientada a Objetos Aplicada:** Uso de conceitos de OOP (encapsulamento, herança, composição), separando responsabilidades em classes como `MainWindow`, `FileHandler`, `AnimatedPanel`, `HelpDialog` e `AboutDialog`.
-   **Manipulação de Arquivos em Java:** Como abrir, ler, exibir e fechar arquivos de texto, além de manipular fluxos de entrada e saída (`I/O`).
-   **Construção de Interfaces Gráficas Ricas com Swing:** Criação de menus, painéis, diálogos personalizados, estilização de componentes, adição de imagens e animações.
-   **Threading e Animação:** Implementação de animações usando threads, controle de velocidade e atualização dinâmica de componentes gráficos.
-   **Design Voltado ao Usuário:** Como priorizar a experiência do usuário com interface amigável, acessibilidade, mensagens de status e ajuda integrada.
-   **Tratamento de Eventos:** Uso de `listeners` para ações de menu, botões e ajustes em tempo real.
-   **Customização Visual:** Como implementar efeitos visuais e personalizações em uma aplicação desktop.
